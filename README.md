# Optimo Custom Connector TAC

Same code as the PDX OptimoRoute MCP connector (NwBiofuel-com/haztrack-mcp optimo.js), deployed on Render as optimo-mcp-tac with the TAC OptimoRoute API key (Lowell, 24 Oct 2026: "we are now integrated to two optimo routes ... TAC and PDX"). Env: OPTIMO_API_KEY, MCP_PATH_TOKEN, OPTIMO_ALLOW_WRITES. Endpoint: /mcp/<MCP_PATH_TOKEN>.
